# Global Claude & Copilot CLI Configuration

This directory contains shared configuration for Claude Code and GitHub Copilot CLI.

## Structure

- **`.claude/`** – Claude Code specific configuration
  - `settings.json` – Claude Code client settings
  - `context/` – Context files for Claude Code
  - `CLAUDE.md` – Claude-specific rules

- **`.copilot/`** – GitHub Copilot CLI configuration
  - `settings.json` – Copilot CLI settings
  - `context/` – Context files for Copilot CLI
  - `COPILOT.md` – Copilot CLI specific rules

See AGENTS.md for full documentation of both configurations.
